## 🚀 Featured Projects

### 🏠 [Rob the Block](https://github.com/JKirb52/RobTheBlock)
**Java | LibGDX | Maven | JUnit**

A 2D arcade-style game developed as a group project for CMPT 276 at SFU.

- Four levels with unique layouts and increasing difficulty
- Enemy movement, collision detection, and player interactions
- Rewards, penalties, and a scoring system
- Unit testing for core game mechanics

### 💰 [Expense Tracker](https://github.com/JKirb52/ExpenseTracker)
**Java | Spring Boot | Swing | Maven | JSON**

A desktop expense management application developed for CMPT 213.

- Add, remove, and organize expenses
- Track online purchases and shared expenses
- View yearly and overall spending summaries
- Java Swing interface connected to a Spring Boot REST API

### 💻 [C-Shell](https://github.com/JKirb52/C-Shell)
**C | Linux | CMake | POSIX**

A Unix-style command-line shell developed for CMPT 201.

- Execute external programs using `fork()` and `execvp()`
- Built-in commands including `cd`, `pwd`, `help`, and `exit`
- Command history and history recall
- Background process execution and signal handling
